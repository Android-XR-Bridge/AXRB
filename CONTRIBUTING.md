# Contributing to AXRB

AXRB is MIT-licensed, except for the launcher in `launcher/`, which is
GPL-3.0-or-later. Contributions are accepted under the license of the
component they change. Do not copy GPL-covered launcher code into the
MIT-licensed components.

Only submit material you have the right to contribute. Identify third-party
code and preserve upstream notices. Do not include credentials, game assets,
private logs or personal runtime data.
