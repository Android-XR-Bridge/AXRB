# Contributing to AXRB

Read [LICENSE](LICENSE) and the [coverage list](licenses/source-available-files.txt)
before copying code between components.

For source-available components, public contribution forks and pull requests
are welcome under section 3 of the
[AXRB Source-Available License](licenses/AXRB-Source-Available-1.0.txt).
That permission covers contributions and review, not separately distributed
modified products. You retain ownership of your contributions.

Launcher contributions remain GPL-3.0-or-later. Do not copy restricted native
code into the GPL launcher or GPL-derived code into restricted components.
Third-party and previously MIT-licensed material retains its existing terms.

Only submit material you have the right to contribute. Identify third-party
code and preserve upstream notices. Do not include credentials, game assets,
private logs or personal runtime data. Changes to the coverage list require
an ownership and license check; new files are not automatically covered.

Request separate distribution permissions through this repository's maintainers.
